# Java Day 43 - Employee Payroll Management System

## About
A Java application that manages full-time and part-time employees and calculates their salaries using object-oriented programming.

## Features
- Add full-time employees
- Add part-time employees
- View employee records
- Search employees by ID
- Calculate employee salaries
- Generate total payroll reports
- Save and load employee data using CSV

## Files
- `Main.java` - Main application
- `employees.csv` - Sample employee records

## How to Run
Compile:

`javac Main.java`

Run:

`java Main`

Keep employees.csv in the program's working directory.

## Concepts
- Abstract classes
- Inheritance
- Method overriding
- Polymorphism
- ArrayList
- File handling
- Exception handling
